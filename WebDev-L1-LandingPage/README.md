# NOVA – Creative Digital Studio

## Project Overview

NOVA is a responsive landing page created as part of the Oasis Infobyte Web Development Internship.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Web Design

## Features

- Sticky navigation bar
- Hero section with call-to-action
- Features section
- About section
- Responsive layout
- Footer with contact and social placeholders

## Project Structure

- `index.html` – Main webpage
- `style.css` – Styling and responsive design
